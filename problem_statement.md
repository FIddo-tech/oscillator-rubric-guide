# Problem statement

A mass m = 0.5 kg is attached to a linear spring with stiffness k = 50 N/m and viscous damping b = 0.4 kg/s. It is driven by F(t) = F0 cos(omega t) with F0 = 10 N.

Use the standard form

    x'' + 2 gamma x' + omega_0^2 x = (F0 / m) cos(omega t)

and write the steady state as x_p = A cos(omega t - delta), where delta is the phase lag.

## Tasks

1. Write the governing differential equation for x(t) with units.
2. Find omega_0 and gamma.
3. Derive A(omega) and delta(omega) for all omega >= 0.
4. Evaluate A and delta at omega = omega_0.
5. Find the transient decay time tau.
6. Check the limits omega -> 0 and omega -> infinity and interpret them physically.
